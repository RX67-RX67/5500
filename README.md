## Motivation & Overview
This project is a personal experiment and a way to practice building a data pipeline (ETL), while also exploring how algorithms can help solve a real-world problem that keeps popping up in the author's life.

As the author enters graduate school, he finds it increasingly important to manage his time efficiently. But it's not an easy task — beyond his regular routines like taking classes and doing homework, unexpected things always seem to happen: friends suddenly want to hang out, or an interesting academic event shows up out of nowhere.

To save some brainpower for more meaningful things, he decided to build a little helper using what he’s learned about data structures, algorithms, and data pipelines.
